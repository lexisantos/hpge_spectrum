# Activación_HPGe

## Repo_HPGe

Contiene funciones útiles para el análisis de espectros (.txt, usando _export_ del software GammaVision, de ORTEC). Sirve para las calibraciones en eficiencia, cálculos de flujo y actividad por pico, descarga de datos del Livechart de la IAEA usando su API.

## Analisis_HPGe

Llama las funciones del script anterior para casos concretos. Útil para cuando se deja midiendo por jobs (seguimiento del Fondo, suma de espectros, actividades en función del tiempo). Definición de alambres, y cálculo del flujo neutrónico al final de la irradiación, para distintos tiempos de espera post-irradiación. Actividad de pico incógnita.
